# C# source links

Two generator options add a source location to every generated doc comment for
messages, fields, enums, enum values, extensions and service methods:

- `source_links=<template>`: a URL template that must contain `{path}` and
  `{line}`. `{path}` is the proto-path-relative file name, URL-encoded per path
  segment (`/` kept); `{line}` is the one-based declaration line.
- `source_links_text_prefix=<prefix>`: prepended to the visible `path:line`
  text. Without a template, the remark is this plain text and has no link.

Pass both as one quoted argument; the template must not contain `,`, which
separates generator options:

```text
"--csharp_opt=source_links=vscode://codepit.codepit-vscode/open-source?path=Assets/holosweat/api/{path}&line={line},source_links_text_prefix=Assets/holosweat/api/"
```

produces, for a field declared on line 62:

```csharp
/// <remarks>Source: <see href="vscode://codepit.codepit-vscode/open-source?path=Assets/holosweat/api/holosweat/proto/client/db/user.proto&amp;line=62">Assets/holosweat/api/holosweat/proto/client/db/user.proto:62</see></remarks>
```

Without either option the output is unchanged. Declarations without source
locations, and `experimental_strip_nonfunctional_codegen`, emit no remarks.
Services are generated by a separate plugin (e.g. `grpc_csharp_plugin`), which
does not receive `--csharp_opt`.

## C++ build compatibility

The CMake build supports C++14 even though the repository's Bazel default is
C++17. Source-link option presence uses `absl::optional`: replacing it with
`std::optional` breaks the C++14 build. The `options_cxx14_test` target compiles
the actual options header in C++14 and checks omitted, empty, populated and
reset values. Run it with the other C# compiler tests:

```
bazel test //src/google/protobuf/compiler/csharp:all
```
